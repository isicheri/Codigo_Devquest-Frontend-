# ⚡ Stake Pool Dashboard

A sleek and responsive dashboard for interacting with a Solana-based stake pool smart contract. Built with modern technologies like React, ShadCN UI, Tailwind CSS, and the Solana Wallet Adapter. The smart contract is deployed and managed via the [Codigo Platform](https://codigo.ai/).

## ✨ Features

- 🔒 Connect with Phantom wallet and other Solana-compatible wallets
- 📊 Visual stake stats and real-time updates
- 📥 Stake SOL directly to the pool
- 📤 Withdraw your staked SOL
- 💡 Light/Dark theme toggle
- 📱 Fully responsive design
- 📦 Powered by ShadCN UI and TailwindCSS

---

## 🛠 Tech Stack

- **Frontend**: React + Vite
- **UI Library**: ShadCN UI (Radix + TailwindCSS)
- **Blockchain**: Solana + Anchor + Codigo
- **Wallet Integration**: Solana Wallet Adapter
